## Version 2.2.2 Files 

* NGI-5000-Logic_2.2.2_arm64.deb - Debian install package for CM4

## Release Kind

Release Candidate.

## Intended Use and Users

This is the NGI-5000 CM4 Logic Module Software Package. It installs software on the CM4 for use in configuring and monitoring engine firing.

It is for use by customers.

## What has Changed from Previous Version

N/A

## What Has Been Fixed

* Fix for bank B being the same firing angles in the engine config tool as bank A in the NGI-5000 full system mode which caused some firing patterns to not fire bank B at the correct angles.
