## Release Kind

Preview Release.

## Intended Use and Users

This is the NGI-5000 CM4 Logic Module Software Package. It installs software on the CM4 for use in configuring and monitoring engine firing.

It is for use by customers.

## What has Changed from Previous Version

* Adding preview release for a firing pattern for LSV 12 cylinder that is an X8L. This was listed as X4L and a special pattern and was not able to be selected. It also followed the CPUII convention and still had X4L. This LSV has 2 plugs per cylinder with a firing pattern of 4-36-4-80 as a 4 stroke.
