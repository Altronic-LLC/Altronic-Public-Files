## Version 10-11-23 Files 

* NGI-5000-CRC-10-11-23.bin - Logic ST micro firmware

## Release Kind

Final Release.

## Intended Use and Users

This is the NGI-5000 Logic Module ST micro firmware.

It is for use by customers.

## What has Changed from Previous Version

* Shutdown input on start up now recognized without unplugging and plugging back in
* 2 stroke mode, the NO HE signal may light.
* High voltage warnings with no high voltage numbers above threshold
