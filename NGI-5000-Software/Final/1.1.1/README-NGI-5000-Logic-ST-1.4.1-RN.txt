## Version 1.4.1 Files 

* NGI-5000-20240918-1.4.1.bin - Logic ST micro firmware

## Release Kind

Final Release.

## Intended Use and Users

This is the NGI-5000 Logic Module ST micro firmware.

It is for use by customers.

## What has Changed from Previous Version

* Changed the file name to use the yyyymmdd format in the name. This allows for names to be in ascending or descending order on your PC or thumb drive
* Adds filtering for the 4-20mA that deglitches the alarm output and has to see a 4-20 signal drop out for 1 second before setting the alarm output
