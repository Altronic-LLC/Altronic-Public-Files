## Version 1.4.2 Files 

* NGI-3000-Logic_1.4.2_arm64.deb - Debian install package for CM4

## Release Kind

Release Candidate.

## Intended Use and Users

This is the NGI-3000 CM4 Logic Module Software Package. It installs software on the CM4 to configure software needed for configuring and monitoring the engine.

## What has Changed from Previous Version

- AWI screens have been updated (AWI v3.37, Register List Version v2.2.0).
- Full firing pattern code (e.g. C2A180.FA#001) is now shown on the AWI and Config Tool
- Default current map retard in the Config Tool is now 3 degrees to match the CPU-95

## What Has Been Fixed

- AWI Fixes
  - Global timing display is now correctly shown on the top screen instead of reset pin angle
  - Touchscreen scrolling within the menu has been improved
